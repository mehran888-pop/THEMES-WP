A calm global WooCommerce theme with Elementor widgets, shop, product, cart, checkout and account layouts.

== Description ==

Orvio is a WooCommerce theme with Elementor support, RTL layout, a settings panel, and templates for the shop, product, cart, checkout invoice and customer account.

== Installation ==

1. Copy the `orvio` folder into `wp-content/themes/`.
2. Activate Orvio.
3. Install WooCommerce and Elementor.
4. Open the Orvio menu and install the demo catalog.
